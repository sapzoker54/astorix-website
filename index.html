Platform Architecture

Enterprise-Grade AI Infrastructure

Built on Microsoft Azure with enterprise security, real-time data pipelines, and scalable AI services.

Real-Time AI Analytics

Socrata open data pipelines, Azure Functions timer triggers, and Cosmos DB delivering live city intelligence every 60 seconds.

Enterprise SSO

Microsoft Entra ID multi-tenant single sign-on. Bearer token authentication. MSAL Browser v3 integration for enterprise identity.

Geospatial Intelligence

Mapbox GL interactive maps. District boundaries, incident overlays, heat maps, and satellite layers for spatial situational awareness.

NoSQL Data Platform

Azure Cosmos DB serverless — East US. Multi-collection: cityinfra, housing, incidents. Auto-scaling for enterprise data volumes.

PWA — Downloadable Software

Each ASTORIX module is installable as a Progressive Web App. Download and run as a desktop or mobile application — fully offline-capable.

CI/CD Auto-Deploy

GitHub Actions pipeline. Auto-deploy on push to main. Azure Monitor + Log Analytics. Zero-downtime deployments across all modules.
